# A/B Test Analysis: Recommendation System & Engagement Metrics

Проект посвящен анализу результатов A/B-тестирования для онлайн-стриминга. Цель исследования — оценить влияние новой системы рекомендаций (или интерфейсных изменений) в группе **B** по сравнению с контрольной группой **A** на ключевые пользовательские метрики: время просмотра, количество сессий и конверсию в подписку.

---

## Этапы предобработки данных
* Нормализация категориальных признаков: Приведение к единому регистру и исправление опечаток в типах подписок (prem, premiumium -> premium, standard -> standart)
* Логическая валидация:
    Удаление записей с отрицательным watch_time
    Фильтрация нереалистичного возраста (age от 0 до 100 лет)
    Проверка условия: movies_started >= movies_finished
* Удаление дубликатов и пропусков: Повторяющиеся логи и строки с NaN удалены
* Обработка выбросов (IQR): Фильтрация аномальных значений watch_time с помощью интерквартильного размаха ($IQR = Q3 - Q1$)

---

## Ключевые метрики
* watch_time - Суммарное время просмотра
* sessions - Количество сессий пользователя
* movies_started / movies_finished - Динамика и досматриваемость контента
* clicked_recommendation - Взаимодействие с блоком рекомендаций
* subscription_bought - Конверсия в целевое действие (покупка подписки)
